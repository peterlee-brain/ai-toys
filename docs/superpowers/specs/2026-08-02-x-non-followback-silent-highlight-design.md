# X 未回关静默高亮设计

日期：2026-08-02  
状态：已根据用户截图确认

## 背景与目标

当前 `0.2.0` 功能分支已经能扫描用户自己的 X Following 页面，并把确认未回关账号的原生 `Following / 正在关注` 按钮显示为橙红色。但现有固定“未回关”扫描面板仍会覆盖页面右侧内容；用户截图明确要求这块面板完全不出现。

本改动将扩展改为静默显示模式：扫描和缓存逻辑继续运行，页面只呈现原生 Following 按钮上的未回关高亮，不再显示扩展自己的悬浮面板。

## 方案选择

采用“保留面板控制器、从布局中隐藏根节点”的最小改动方案。固定面板根节点仍由现有控制器维护扫描状态，但专用 CSS 将其完全移出页面布局和可见树。

与重写为无面板控制器相比，这一方案改动范围更小，不触碰已经验证过的扫描、缓存、暂停和清理生命周期。与折叠成小徽标相比，它严格满足截图中“页面不出现插件面板”的要求。

## 可见行为

- `#x-non-followback-root` 不占据页面空间，不响应鼠标或键盘操作，也不出现在视觉界面中。
- 已加载且确认未回关的账号，其 X 原生 `Following / 正在关注` 按钮继续显示橙红色高亮。
- 互相关注、关系无法确认或按钮身份无法精确识别的账号保持 X 原样。
- 用户点击原生按钮时，行为仍完全由 X 页面处理；扩展不代理点击。

## 内部行为与安全边界

- 内容脚本进入用户自己的 `/following` 页面后继续自动扫描当前已加载卡片。
- 原有本地缓存继续按登录账号隔离保存。
- 不自动滚动、点击、关注或取消关注。
- 不新增权限、后台脚本、X API、外部网络请求、遥测或远程资源。
- 不改变 X 原生按钮的文字、事件监听器、可访问性属性、禁用状态或点击区域。

隐藏面板意味着页面上不再提供“暂停扫描”和“清空”按钮。扫描生命周期仍保留内部暂停与清理能力，用于路由离开、页面卸载和异常保护；用户重新加载扩展或页面即可重新启动扫描。

## 实现边界

只修改 `x-non-followback/src/styles.css` 及其静态样式测试：

1. 为 `#x-non-followback-root` 设置 `display: none !important`，确保现有面板不会出现在页面任何一侧。
2. 保留 `.x-nfb-following-highlight` 的现有按钮高亮样式。
3. 不改动 `content.js`、`panel.js` 的扫描和状态机逻辑。
