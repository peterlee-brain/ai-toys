# X 未回关按钮高亮

一个本地、只读的 Chrome 扩展。你在自己的 X Following 页面正常向下滚动时，它会静默收集已经加载的账号，并把没有“关注了你 / Follows you”标记的账号原生 Following 按钮点亮；本次打开页面后，每个未回关会在 Following 按钮左侧显示递增序号（1、2、3…），方便你边滑边判断扫到哪。页面不会显示额外面板。

## 安装

1. 在 Chrome 地址栏打开 `chrome://extensions`。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择 `ai-toys/x-non-followback` 目录。
5. 登录 X，打开自己的 `https://x.com/<你的账号>/following`。

修改源码后，在 `chrome://extensions` 中点击本扩展的刷新按钮，再刷新 X 页面。

## 使用

1. 打开自己账号的 Following 页面；扩展会在页面内静默运行，不显示悬浮面板。
2. 正常向下滚动列表；扩展只扫描 X 已经加载的账号。
3. 已确认未回关账号的原生 `Following / 正在关注` 按钮会显示橙红色描边、浅色背景和光晕；按钮行为仍完全由 X 处理。
4. 每个未回关账号的原生 Following 按钮左侧会出现本次会话递增序号；序号不拦截点击。刷新页面后从 1 重新计。
5. 页面不再提供暂停或清空控件。离开 Following 页面或刷新页面时，运行时会自行停止和重建。

扫描结果按 X 账号分别保存在 `chrome.storage.local`。刷新页面后可以恢复，但它始终只代表你已经滚动加载过的卡片；扩展无法凭空读取尚未加载的完整 Following 列表。

## 安全边界

- 只请求 `storage` 与 `https://x.com/*` 权限。
- 不要求密码、OAuth、Cookie 或 API Token。
- 不包含后台进程、外部服务、远程脚本、广告或遥测。
- 不调用 X API，也不发送 `fetch`、XHR、WebSocket 或 Beacon 请求。
- 不自动滚动、点击、关注或取消关注。
- 不提供批量取消关注按钮。
- 只给可靠识别出的原生 Following 控件添加或移除 CSS 类，不注册新的点击处理。

这是第三方本地扩展，并非 X 官方产品。虽然它只读页面且不自动操作账号，仍建议安装前直接查看 `manifest.json` 与 `src/` 源码。

## 支持范围

- Chrome 桌面版，Manifest V3。
- X 页面语言：英文、简体中文、繁体中文。
- 只在当前登录账号自己的 `/following` 页面扫描；打开其他人的 Following 页面不会启动。
- 依赖 X 当前的 `data-testid="UserCell"` 和侧栏个人资料链接。回关文案必须在卡片中显示为独立一行；如果 X 修改页面结构，扩展会停止本轮扫描以避免继续产生不可靠结果。

## 常见问题

### 页面没有出现悬浮面板

这是静默模式的预期行为。确认扩展版本为 `0.2.5`，然后观察未回关账号原生 Following 按钮是否出现橙红色高亮，以及按钮左侧是否出现 1、2、3… 序号。

### 所有人都显示为未回关

先不要依据高亮集中操作，并离开 Following 页面。确认 X 卡片仍显示“关注了你 / Follows you”文字；如果 X 更改了文案或结构，需要更新 `src/core.js` 的关系识别规则。

### 未回关账号的按钮没有高亮

确认扩展版本为 `0.2.5`，在 `chrome://extensions` 点击扩展的刷新图标，再刷新 X 页面并继续手动滚动。扩展只匹配完整的 `Following / 正在关注` 等已关注文案；无法可靠确认身份的按钮会保持原样。

### 提示本地缓存读取、保存或清空失败

扩展会停止扫描并保留当前页面中的结果，避免把旧缓存覆盖成空数据。确认扩展仍有本地存储权限后，重新加载扩展并刷新 X 页面重试。

### 怎样扫描全部账号

保持页面打开并手动滚动到列表底部。扩展刻意不提供自动滚动，以降低自动化行为和账号受限风险。

```bash
node --test tests/*.test.js
node --check src/core.js
node --check src/panel.js
node --check src/content.js
node -e "JSON.parse(require('node:fs').readFileSync('manifest.json', 'utf8'))"
```

视觉夹具位于 `tests/manual-fixture.html`，可用任意本地静态服务器打开。
